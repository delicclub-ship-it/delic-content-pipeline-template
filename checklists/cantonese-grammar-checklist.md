# 粵語口語語法檢查表 | Colloquial Cantonese quality checklist

> 適用：口播稿／字幕／圖卡文字（繁體粵語書面）。
> 兩層：Layer 1 機械掃描（可以寫成腳本，或叫 AI 助理逐項檢查）；Layer 2 人手語意 review。
> Layer 1 有 🔴 → 改完清零先入 Layer 2。

## Layer 2：語意 review（逐段問） | Semantic review

### Q1 主謂賓完整？

每句掃一次：狀態動詞冇對象？動作動詞冇受詞？子句斷半？
例：❌「不斷明你」→ ✓「不斷明白你嘅處境」

### Q2 狀態動詞＋時間副詞自然？

硬湊組合會聽落怪。
例：❌「持續識呢套方法」（「識」聽落似結識）→ ✓「持續用呢套方法」

### Q3 「等／讓」用得啱？

粵語「等」多數＝等候；表達 so that 用「讓」更安全。
例：❌「等我哋可以持續成長」→ ✓「讓我哋可以持續成長」

### Q4 同概念用字一致？

同一概念全稿一個寫法。做法：每個概念詞搜尋一次，確認冇第二種寫法。

### Q5 朗讀順唔順？

腦內讀一次：卡住／要重讀／語氣斷＝標示。常見原因：句太長、修飾語疊埋、pause marker 打斷語意、主語轉太快。

### Q6 因果 bridge 完整？（防無頭無尾）

見到跳躍詞就停：嗰刻／突然／忽然／於是／所以／因此／我意識到／我發現／之後／然後。
問：「上一句 → 呢句，需要嘅 inference 有冇寫咗出嚟？」答案淨係喺你腦入面＝fail。

例：

- ❌「阿明考試肥佬。嗰刻我明白，努力冇用。」（點解肥佬＝努力冇用？冇講）
- ✓「阿明考試肥佬，事後發現佢淨係背書唔理解。嗰刻我明白，唔理解嘅努力好易白費。」

高危情境：長稿壓短稿（bridge 被砍）、跟模板逐段填（段內通順跨段跳）、AI 預設聽眾識 fill in the blank。
修法：唔係加長，係補返 missing 嘅因果 step。

### Q7 書名／引用規則一致？

{{your-citation-style}}——重點係**全稿一致**：正文、字幕、caption 用同一套寫法。

### Q8 口播稿避用「：」「—」？

TTS／配音對呢啲標點讀得差。冒號→句號、破折號→逗號；停頓交俾 pause marker。
（淨 check 口播稿；字幕／heading 保留原標點。）

### Q9 標題唔好概念直譯？

每個章節 heading／關鍵 label 問三條：

1. 係概念名稱定活人語言？（測試：「一個講粵語嘅人會自然咁講出嚟咩？」）
2. 施事者有冇消失？（有人被影響／被設定，要講到係邊個做）
3. 係咪普通話／英文 pattern 直譯落嚟？

例：❌「理想自我的實現」→ ✓「行近你想成為嘅嗰個人」

### Q10 比喻閉環？

一段入面比喻場景要維持同一個（揸車就揸到尾，唔好中途變行路）。金句段特別易跳。

### Q11 歧義／食字／聽覺嵌套？

歧義字詞（可以引申錯誤聯想）、相鄰同音字要加字隔開、多層引文要拆句。

### Q12 史實／斷代保守？

名人軼事有疑點改用安全版本；唔好講實「同一個時代」，用「相近嘅年代」；理論細節全稿統一。

### Q13 跨集一致？

系列名／概念名／次序要同總綱一致；定期全文搜尋核對一次。

### Q14 口播語境適配？

用「聽眾／觀眾」唔用「讀者」；用香港慣用語；清理人名前後異常空格。

### Q15 逐句聽眾測試（7 條） | Listener test

任何一條 fail 就標示：

1. 聽完答唔答到「邊個（主語）做咗咩（動詞）對咩（受詞）」？
2. 一句一意圖（陳述／發問／解釋／邀請）？超過一件＝拆句。
3. 指代有冇落地（「呢句／呢樣／係咁」指緊咩）？上文冇 antecedent＝fail。
4. 結構連接詞（而係／因為／所以／但係／如果）有冇被剪？剪走＝fail。
5. 排比子句係咪同構（同一句式）？
6. 引文前係逗號＋停頓，唔係句號另起？
7. 有冇兩種合理解讀？有＝改到得一種。

嚴重度：🔴 定稿前必改；🟡 建議改。
輸出 audit log 表：位置／原句／問題類型／建議改寫／嚴重度。

## 高頻陷阱速查 | Common pitfalls

| 錯 | 對 | 原因 |
|---|---|---|
| 變左／咩野／你既 | 變咗／咩嘢／你嘅 | 香字／形近字 |
| 和（連詞） | 同／同埋 | 「和」係書面 |
| 讀懂 | 明白 | 「讀懂」係書面 |
| 腳本（口播內容） | 劇本 | 粵語慣用「劇本」 |
| 修飾語並列漏「嘅」 | 我自己設計**嘅**、同埋…嘅系統 | 並列時第一個易漏 |
| 狀態動詞＋時間副詞硬湊 | 揀個自然搭配 | 「持續識／一路知」呢類組合聽落怪 |
| 長稿壓短稿砍 bridge | 補返因果 step | 見 Q6 |
| 引用學者／學術內容時書面化 | 全句轉口語 | 書面直譯最易漏「了／的／來／是」 |

## TTS 讀音替代機制 | TTS pronunciation substitutions

TTS 會有讀唔出／讀錯嘅字。集中管理一張替代表，唔好逐次臨場改：

- **純語音替代**：淨改餵俾 TTS 嘅稿（同音／近音字），字幕同畫面文字保留原字。
- **書面等價替代**：書面本身都算錯嘅字，全域改（字幕／畫面一齊改）。
- 每條替代記錄三樣：原字 → 替代字、適用範圍、原因。
- 驗收以**人耳**為準：出聲後逐條測；自動檢查會有假陰性。
